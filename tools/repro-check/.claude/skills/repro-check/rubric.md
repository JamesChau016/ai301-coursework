# Rubric: is this reproduction package ready to post?

## Checks

| Check                 | Evidence                                                                                                  | Pass condition                                                                                                                                                                                                                                                                                  | Weight   |
| --------------------- | --------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| env-recorded          | The environment block in the reproduction report read against the target system requirements              | Pass if the report explicitly specifies both the exact Operating System (with version) and the tool/software runtime version used during testing.                                                                                                                                               | required |
| steps-complete        | The reproduction steps section of the report read against the claimed behavior                            | Pass if a stranger can follow the commands or explicitly identified issue-provided script and reach the documented execution state without guessing any behavior-critical setup, configuration, input, or parameter; routine boilerplate may be summarized when it does not affect the trigger. | required |
| behavior-matches      | The output excerpt or logs in the report read against the original issue description                      | Pass if the recorded error or observable behavior precisely mirrors the core symptom described in the target issue, or if a controlled attempt clearly shows the core symptom is absent and records the contrasting output rather than an unrelated setup failure.                              | required |
| honesty-check         | The final conclusion section of the report read against the observed test outcomes                        | Pass if the report honestly declares the true test result—accepting an evidenced cannot-reproduce outcome as validly as a successful reproduction, without forcing a false-positive success.                                                                                                    | required |
| current-version-check | The report's environment and verification statements read against the issue and repo-facts requirements   | Pass if the report verifies the behavior on the latest version and main branch whenever the repo's bug-report requirements ask for both; otherwise pass when no such requirement is stated.                                                                                                     | required |
| conventions-check     | The language and formatting of the comments read against the repository's contributing norms and policies | Pass if the commentary follows local disclosure expectations (including explicitly naming the AI tool and extent of assistance when the repo requires AI disclosure) and maintains a professional tone.                                                                                         | required |

## Verdict rule

Accept the package if and only if every required check passes. Any `unclear` grade on a required check counts as a fail, resulting in a `reject` verdict.
